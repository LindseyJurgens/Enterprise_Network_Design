A university networking case study focused on planning and documenting network infrastructure across multiple international locations.
The project explores network topology, IP addressing, subnet allocation, server infrastructure and networking hardware selection.
Completed as part of Bachelor of Information Technology coursework, demonstrating foundational knowledge of computer networking and infrastructure design.
Skills demonstrated include:
- Designing multi-site LAN, WLAN and WAN topology diagrams.
- Planning IPv4 subnet allocations and address ranges.
- Documenting router interfaces, static addressing and DHCP ranges.
- Planning server connectivity and backup infrastructure.
- Evaluating networking hardware using weighted decision matrices based on cost, performance, security and scalability.
